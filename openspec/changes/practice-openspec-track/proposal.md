## Why

Автор проекта уже использует OpenSpec, но хочет систематизировать знания и обнаруживать пробелы через короткую практику с объяснением ошибок. Первая итерация проверяет полезность полного учебного цикла на одном подготовленном треке; одна сессия не считается доказательством устойчивого освоения навыка.

## What Changes

- Добавить русскоязычный трек «OpenSpec: от идеи до проверенного изменения» с целью Improve, картой навыков и одной фиксированной последовательностью пяти заданий: два multiple choice и три open answer.
- Подготовить задания, рубрики и постоянные ссылки на одну закреплённую ревизию официальной документации OpenSpec до запуска тренировки.
- Проверять multiple choice детерминированно, открытые ответы — через OpenAI API по рубрике и выдержкам источника; показывать выполненные критерии, категорию «верно / частично / неверно», объяснение и источник.
- Сохранять черновик, принятый ответ и результат проверки; восстанавливать сессию после перезагрузки. Техническая ошибка допускает повтор проверки того же ответа и не становится учебной ошибкой.
- Запретить изменение принятого ответа; повторная практика создаёт новую сессию после завершения текущей.
- Показывать сохранённый итог по проверенным навыкам со ссылками на конкретные ответы; непроверенные навыки оставлять без оценки.
- Запускать первую версию локально, для одного пользователя, без авторизации. Предусмотреть бюджет $5 на эксперименты с API и учёт расходов.

## Capabilities

### New Capabilities

- `openspec-track`: готовый трек, карта навыков, версия источников и контракт пяти подготовленных заданий.
- `practice-session`: последовательное прохождение, сохранение, восстановление, повторная отправка и завершение сессии.
- `answer-assessment`: проверка ответов, обратная связь, обработка технических ошибок и критерии качества AI-оценки.
- `session-results`: сохранённые результаты сессий и осторожные выводы по проверенным навыкам.

### Modified Capabilities

Нет: в проекте пока нет основных спецификаций и реализации приложения.

## Impact

Потребуются новый React/TypeScript интерфейс, локальный сервер с API, PostgreSQL, серверная интеграция OpenAI через AI SDK, валидация Zod и набор примеров для оценки качества. Подписка ChatGPT не подтверждает наличие оплаченного API: настройка ключа и API-биллинга остаётся предпосылкой реальной проверки. Исходная основа — `docs/product-context.md`; уточнения по запуску, бюджету и повторным попыткам согласованы с пользователем при планировании.

## Non-goals

Пользовательские треки, импорт книг, RAG/embeddings, чтение с AI, заметки, экзамены, генерация заданий на лету, адаптация, интервальные повторения, многопользовательский доступ, публичное размещение, числовые mastery/confidence и доказательство эффективности обучения не входят в итерацию.
