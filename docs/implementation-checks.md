# Проверка practice-openspec-track

Проверено 2026-10-11. Реальные вызовы OpenAI API не выполнялись: пользователь добавит ключ позднее.

- `npm test`: 18 проверок прошли. Использовалась отдельная временная схема PostgreSQL. Проверены конкурентное создание сессии и отправка ответа, неизменяемость, переходы, технические ошибки провайдера и валидации, сбой записи оценки, резерв расходов, поздний ответ, отсутствие ключа, неподтверждённый тариф, исчерпание бюджета, история и смешанные результаты навыка. Проверены два запуска отдельного серверного процесса с теми же данными, включая активную и завершённую сессии.
- `npm run test:browser`: 3 сценария прошли в Chromium с тестовым оценщиком. Полный цикл пяти заданий; перезагрузка черновика, ожидания и обратной связи; технический retry; история и новая сессия; мобильный экран без горизонтальной прокрутки; клавиатура и сообщение об ошибке localStorage.
- `npm run build`: TypeScript и production-сборка проходят.
- `npm run format:check`: проходит.
- `npm run eval:check`: 21 пример × 2 прогона подготовлены без платных вызовов. Верхний резерв по указанным тарифам — $0.6615.
- React Doctor: 85/100, ошибок нет. Оставшиеся предупреждения — сложность формы и три поиска по коротким массивам рубрики/источников. Сравнение с HEAD недоступно, поскольку исходный репозиторий ещё не содержит коммитов; выполнено полное сканирование.
- PostgreSQL перезапущен: миграция и бюджет сохранены в постоянном volume. Повтор миграции не сбрасывает данные.
- Скриншоты desktop/mobile и результатов созданы в игнорируемой `test-results/`; проверены визуально.

Готовы каркас, контент, сессии, UI, серверный оценщик, ограничения расходов и инструмент eval. Качество реальной AI-оценки пока не подтверждено. После настройки `.env` нужно выполнить `npm run eval`, разобрать расхождения и объяснения по источникам, затем пройти личную тренировку и записать обратную связь. Поэтому задачи 6.1–6.3 и 6.6 остаются незавершёнными; изменение не готово к архивированию как полностью принятое.
