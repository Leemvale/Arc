# Источники первой тренировки

Пакет `openspec@1.0.0` подготовлен по commit `9111a7654d7800391459431fff4eaf66e33a3d2e` репозитория Fission-AI/OpenSpec. Ревизия выбрана до написания заданий; прочитаны Getting Started, Concepts и Commands. Ссылки разделов находятся в `content/track.ts`. Поле excerpt содержит краткое изложение источника для оценщика, а не дословную цитату.

В этой ревизии профиль core включает propose, explore, apply, update, sync, archive. Команды расширенного workflow включаются отдельно. Этот upstream не следует отождествлять с установленным рабочим форком пользователя.

Покрытие: задания 1 и 3 — основные и change specs; 2 и 4 — назначение артефактов; 5 — проверяемый сценарий. Операции delta specs, workflow и проверка реализации остаются на карте без оценки.
